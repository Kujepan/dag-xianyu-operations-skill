# 大G的闲鱼运营skill

一个 Codex Skill，用来整理闲鱼选品、商品上架、固定话术回复和付款后发货。支持按商品或批次执行，也可以从已有商品 ID 接着做配置核验。

## 使用

1. 将本仓库的 `skills/xianyu-operations` 目录放到 Codex 的用户技能目录（默认是 `~/.codex/skills`）。
2. 在 Codex 里调用 `$xianyu-operations`，并提供任务卡、商品信息或历史回执。
3. 实时发布、回复和发货由账号已开通且获平台许可的渠道执行。首次使用可先用本地数据生成草稿并核对绑定。

```text
用 $xianyu-operations 整理这批商品。根据关键词样本给出选品依据，
为已确认的商品准备上架草稿、固定话术和付款后发货绑定。
```
