# 大G的闲鱼运营skill

用一个 Codex Skill 串起闲鱼选品、上品、关键词回复和付款后发货。可以处理一批商品，也可以拿着已有商品 ID，只做回复、发货或对账。

**装好就能用本地资料做选品分析、上架草稿和绑定表。** 实时发布、回复和发货需要另行接入账号已开通、且获闲鱼许可的在线服务。

## 安装

在 Codex 里发送这句话：

```text
用 $skill-installer 安装 GitHub 仓库 Kujepan/dag-xianyu-operations-skill
的 skills/xianyu-operations 目录。
```

也可以下载仓库，把完整的 `skills/xianyu-operations` 文件夹复制到项目的 `.agents/skills/`，或个人的 `~/.agents/skills/`。安装后的路径末尾是 `xianyu-operations/SKILL.md`。如果 Codex 没显示新技能，重启后再试。 [OpenAI Docs 的 Skill 安装说明](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills)

## 从一个商品开始

下面用一份自制的「每周计划表 PDF」举例。每一步都可以单独调用。已有在售商品时，拿商品 ID 直接从回复或发货开始。

### 1. 选品

先从你自己的行业词或闲鱼榜单找线索，两个入口可以一起用。

- **已经知道做哪个行业**：在闲鱼 App 搜自己的行业词，再按用途、人群、规格或交付形式细化。比如做教辅，可以从「小学教辅」细化到「一年级拼音练习」。本教程的「每周计划表」「A4 周计划」是计划表这个示例的搜索词。
- **想找新方向**：查看鱼小铺工作台中账号能看到的缺货榜、趋势榜或爆卖榜。先选相关类目，把榜单名称、日期或周期、排名、上榜词和页面显示的指标截下来。挑出你能提供的几个方向，再用上榜词和具体交付词回闲鱼 App 搜同类商品。 [闲管家卖家攻略](https://xygj.pro/website/content?article_id=498458897921413&category_id=undefined&title=%E6%B5%81%E9%87%8F%E6%9B%9D%E5%85%89&type=21)

**先出词。** 告诉 Codex 你的行业、目标买家和能交付什么。手上有榜单截图也可以一并附上。让 Skill 输出一份**每行一个词**的采集清单，先列核心商品词，再补人群、用途、规格或交付方式等细分词。也可以把你已有的种子词直接交给 Skill。

```text
用 $xianyu-operations 给［行业］出一版闲鱼采集词。
我的目标买家是［人群］，能提供［产品或服务］。
结合我附上的榜单线索，输出 10 个词，每行一个，先出词。
```

**再采集。** 有获许可的搜索入口时，把清单交给 Skill 逐词采集。也可以自己在闲鱼 App 搜，把截图或表格交给 Codex。第一轮可按同一种排序每词取前 10 条，记录搜索词、日期、商品 ID 或链接、标题、挂牌价、可见的想要数和实际交付形态。起价、多规格价格和缺失字段照页面记录。

```text
用 $xianyu-operations 按这份词表采集，每词取综合排序前 10 条。
有可用接入就采集并按商品 ID 去重。用我提供的截图或表格时，按相同字段整理。
请保留每条数据的来源、采集日期和缺失字段。
```

**最后筛选。** 比较同类商品的卖点、价格和交付内容，输出候选和依据。把榜单排名、挂牌价和已核到的成交数据分别记录。选定方向后再上品。

### 2. 上品

1. 提供已选定的商品、主图、售价、描述要点和交付内容。数字商品写清文件格式、买家怎么领取，以及是否需要登录或转存。
2. 让 Skill 生成标题和详情草稿，核对目标账号实际支持的类目及发布字段。
3. 需要实际发布时，指定账号和发布范围。通过已接入的发布渠道提交后，从卖家端回查标题、商品 ID、链接和状态。已有商品时直接复用它的 ID。

```text
用 $xianyu-operations 给我自制的每周计划表 PDF 做一份闲鱼商品草稿。
用我附上的主图，定价 1.99 元。交付一份 A4 可打印 PDF。
请输出标题、详情和待核对的类目字段。
```

**本步产出**是可填写的商品草稿。实际提交后，回执会注明「在售」「审核中」或平台返回的实际状态。

### 3. 自动回复

1. 提供目标账号、商品 ID，以及确认过的关键词和固定话术。
2. 按商品 ID 整理回复规则。账号接入支持时，把规则配置到对应商品，再回查绑定。未命中、退款或售后咨询留给人工。
3. 用接入服务支持的测试方式核对命中与未命中的结果，确认不会把 A 商品的话术用到 B 商品。

```text
用 $xianyu-operations 为我提供的商品 ID 准备两条固定回复。
「怎么打印」→「用 A4 纸按实际大小打印」。
「是纸质的吗」→「这是电子版 PDF，无实物邮寄」。
请输出关键词、回复内容和商品 ID 的对应表。
```

**本步产出**是商品级回复规则。接入后还可核对规则是否启用、是否绑对商品。

### 4. 付款后自动发货

1. 提供商品 ID、要交付的文件或卡券，以及完整领取步骤。采用目标类目允许的交付入口。
2. 配置「已付款、待发货」触发。接到订单时，用商品 ID 匹配交付内容，再用账号和订单 ID 防止重复发送。
3. 先回查商品与交付内容的绑定。出现首笔真实订单后，再对照付款状态、发送回执和闲鱼上的发货状态。发送结果不明时先查订单记录。

```text
用 $xianyu-operations 为我提供的商品 ID 准备付款后发货绑定。
交付我附上的每周计划表 PDF，领取步骤按已开通的交付入口填写。
请核对商品 ID、触发条件和领取说明，并列出首单需要看的回执。
```

**本步产出**是发货绑定及核验记录。回执记录配置是否已核对，以及真实订单待验证或已履约。

## 什么时候需要在线接入

本地选品分析、商品草稿和绑定表可以直接使用。线上采样、发布、回复和发货需要在接入服务里确认目标账号及对应权限。回复和发货还需要接入服务在线接收消息和订单事件。 [闲鱼社区法律声明](https://terms.alicdn.com/legal-agreement/terms/suit_bu1_taobao/suit_bu1_taobao202103061039_91765.html)

更多字段与接入参考见 [配置与核验](skills/xianyu-operations/references/workflow.md)。
