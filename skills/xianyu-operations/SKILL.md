# 大G的闲鱼运营skill

按本轮要求处理整批商品或指定环节。已有商品 ID、确认过的任务卡和回执可作为接续点。需要商品卡字段、接入说明或验收方法时，读取 [配置与核验](references/workflow.md)。

## 商品信息

每批先确定目标账号。每件记录标题、类目、价格、主图和描述，发布后补商品 ID 和链接。需要回复或发货时，为该商品记录固定问答、交付内容和领取条件。用户已有任务卡时直接沿用。缺少某一步所需的信息时，先完成其他可独立完成的部分。

线上执行使用明确获闲鱼许可且覆盖对应操作的接入，并遵守账号实际开放的能力。当前任务的授权决定可发布、发消息或启用哪些规则。没有可用接入时，照常整理本地草稿、绑定表或对账结果，标明待执行的环节。遇到登录失效、安全校验或账号不符时，暂停该账号的线上步骤。

## 选品

以用户所在行业的关键词或闲鱼榜单为起点。已有行业方向时，优先用用户的行业词、商品词或需求词找同类商品。探索新方向时，读取用户提供的缺货榜、趋势榜或爆卖榜截图、导出及历史回执，记录榜单名称、类目、日期或周期、排名和可见指标。把与用户能力匹配的上榜词用作搜索词，核对同类商品的挂牌价和实际交付。

用户只给行业、目标买家、能交付的内容或榜单线索时，可以先生成采集词。复用用户已有的词表。按商品词、需求词、使用场景、人群或交付方式补充具体搜索词，并去掉重复项。以一行一个词的纯文本输出，可另附优先级和词的来源。用户只要出词时，交付词表即可。收到词表并明确要采集时，使用获许可的搜索接入，或读取用户提供的搜索截图、导出和现有样本。无可用接入或样本时，交付词表和取样口径，标明数据待采集。

使用获授权的搜索入口时，沿用本轮指定的排序、页数和样本数。按商品 ID 去重，保留关键词、采集日期、标题、挂牌价、商品链接、想要数、浏览量和卖家昵称中实际可见的字段。分别记录榜单信号、挂牌价和实际成交，缺失数据标为缺失。输出候选、依据和仍待核实的问题。已有任务卡时，按卡片约定交接选品判断和拍板。

## 采集结果与同步

每轮保存带来源和取样口径的明细以及简短的选品小结。按用户指定的位置落盘或追加到团队文档，已有同步流程时依当前任务的授权执行。没有指定去向时把结果交给用户，文件产物放任务工作区。公开仓库中的文档使用脱敏示例。

## 按商品类型准备交付

数字资料先核对分发依据、类目和实际领取条件。已有网盘链接可按任务核验，需上传、创建普通分享或检查链接时使用已授权且具备对应工具的百度网盘 MCP。推广计佣另核对已开通项目的账号绑定、推广链接及归因，按项目后台的回执记账。服务先确认需求、范围、交付时限和验收点。实物先核对成色、规格、库存及物流方式。

## 上品

用已确认的标题、价格、主图、描述和真实类目生成草稿，复用该商品已有的定稿。数字商品写清实际交付和领取条件，按类目支持的方式交付。涉及第三方软件或资料时，核对适用于该商品的分发依据。发布前核对目标账号和现有商品，避免重复创建。用户已授权且接入、类目和商品资料满足要求时执行发布。发布后回读同一账号的商品列表，记录实际标题、ID、链接和在售或审核状态。提交结果不明时先查列表。

## 自动回复

按账号与商品 ID 绑定已确认的关键词和固定话术，逐件回读匹配关系。未命中、退款或售后咨询交给人工处理。需要处理复杂咨询时，可用已接入的模型生成回复草稿。只有本轮授权了具体范围时才启用生成式回复，模型密钥由接入服务管理。更新单件商品时只处理指定绑定。

## 自动发货

按账号、商品 ID 绑定准确的文件、卡券或平台支持的交付内容。以订单已付款且待发货为触发条件。发前核对订单状态、商品 ID 和交付内容。用账号与订单 ID 去重，失败或结果不明先查发送及发货回执，避免重发。已发出内容和平台显示已发货分别核验。通过平台或服务支持的测试入口做自检，真实订单回执用于核验实际履约。服务预约和需求确认记为履约准备，服务完成后再记录交付。实物发出后按平台支持的方式同步真实运单。

## 上品后的监控和分析

按商品 ID 记录上架时间及标题、主图、价格和规则的改动时间。读取已授权的卖家报表或用户提供的导出，按同一日期范围记曝光、浏览、想要、咨询、支付订单、支付金额、退款和发货异常。区分日增量、累计值、零值和缺失值。定位曝光、浏览、咨询付款及履约环节中的变化，给出证据和下一步测试。按用户指定位置追加复盘。推广归因数据用推广后台的口径另行记录。

## 回执

按实际完成的环节记录状态及证据。选品给来源和样本范围。上品给实际标题、ID、链接和状态。回复给已读回的绑定及运行状态。发货注明配置自检结果，以及真实订单是否触发、发送是否成功、平台状态是否已更新。汇总时对提取码、账号凭据和买家信息做脱敏。
