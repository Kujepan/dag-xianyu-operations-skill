# 配置与核验

## 商品卡

每个商品保留一份任务卡或等价的结构化记录。发布前用商家自定义编号关联素材，发布后用平台返回的商品 ID 关联回复和发货。

| 信息 | 记录内容 |
| --- | --- |
| 选品依据 | 关键词、采集日期、采样范围、候选及证据 |
| 商品 | 目标账号、商家编号、标题、类目、价格、主图、详情 |
| 回复 | 商品 ID、触发关键词、固定回复内容、人工接手条件 |
| 发货 | 商品 ID、交付类型、内容引用、领取步骤、付款触发 |
| 核验 | 实际标题、商品链接、发布状态、绑定回读、订单履约回执 |

交付内容引用保存于卖家可控的配置。账号授权由接入服务管理。

## 接入

- 本地选品可以读取用户提供的关键词样本和市场导出。线上采样使用获得平台许可且支持该操作的接口。
- 发布、消息及订单状态的能力按账号和接入渠道逐项核对。[闲鱼社区法律声明](https://terms.alicdn.com/legal-agreement/terms/suit_bu1_taobao/suit_bu1_taobao202103061039_91765.html)
- 闲管家的开放平台手册说明了自研接入、商品及订单同步和卡密发货。开通后以实际接口和类目支持情况为准。[闲管家操作手册](https://m.goofish.pro/app/operation.html)
- 固定回复和发货需要能够接收实时消息或订单事件的在线服务。离线使用时，可用脱敏回执核对商品与话术及交付内容的对应关系。

## 一次验收

1. 发布后按目标账号回读商品 ID 和状态。
2. 两件以上商品逐件核对各自的问答和交付内容。
3. 按接入服务支持的方式验证未付款、已付款、重复事件和发货结果不明的处理。
4. 保存订单级回执，分别记录发送结果与平台发货状态。
